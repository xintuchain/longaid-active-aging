## 这不是什么

- 它**不评估老人**。手册里没有"能/不能""合格/不合格"这类打分表，也请不要拿它给任何老人贴"成不成功"的标签。
- 它**不提供医疗、心理或法律建议**。涉及健康、用药、纠纷的，请转介专业人员。
- 它**不替代机构登记核验**。手册教你怎么查队伍的"户口"，但最终判断责任在你们机构和主管部门。
- 它**不是学术论文**。书里引用了学术框架，但立场是"帮你换个角度看待手里的资源"，不是给老人做评判。
